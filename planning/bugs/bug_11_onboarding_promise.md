# 11. End-of-Month Flow State Promise in Onboarding

## Description
As a new user, I want the intro text to inspire me by explaining the long-term benefits of the app, so that I am motivated to stick with the habit for a full month.
**Problem Context:** The onboarding currently lacks a strong emotional hook regarding the endgame of using the app continuously.

## Acceptance Criteria
- [ ] A dedicated text block or screen in the onboarding explicitly states: *"If used regularly, by the end of the month you will reach a Flow State so deep that even if someone mentions your name, you won't pay attention."*
- [ ] The copy is localized and stylistically aligned with the app's branding.

## Resolution / Solution Method
- Update the hardcoded strings or localization files for the intro pager.
- Ensure the text fits visually on small screens without breaking the onboarding layout.
- Add an illustration or icon that represents deep focus to accompany this text.
